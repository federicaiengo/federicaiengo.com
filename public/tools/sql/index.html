SQLite · WebAssembly

 
Esegui query SELECT sulle tabelle orders e payments con i dati presenti nella pagina. SQLite funziona nel browser tramite WebAssembly e Web Worker: crea un database temporaneo in memoria a ogni esecuzione, senza inviare i dati a un backend. Richiede i file locali vendor/sql-wasm.js e vendor/sql-wasm.wasm; se non si caricano, controlla la scheda Rete di DevTools. JOIN e Modalità Ufficio restano utilizzabili anche senza SQLite.
